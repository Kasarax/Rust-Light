Genre and style: Sci-fi/cyberpunk interactive adventure book featuring a classic "choose-your-own-adventure" structure (numbered paragraphs, decision points) implemented digitally—complete with dice rolls, a character sheet, and a save system. The visual style evokes a rain-soaked, corporate-dominated megalopolis (Rozsdafény) with a neon-turquoise and magenta HUD aesthetic, teeming with fixers, netrunners, corporate security, and underworld deals.
